# The Clean Home Collection website (coming soon version)

Plain HTML site, no build step.

- index.html : coming soon page with the register-interest form
- my-story.html : My Story page
- privacy.html : privacy notice
- sitemap.xml, robots.txt : help Google find the pages
- images/ : photos (used for link previews on social media)
- favicon.svg : browser tab icon

Sign-up form: connected to the MailerLite form "Website waiting list".

To update the live site, upload everything in this folder to the GitHub repository (drag the images folder in as a folder).
Render settings: Static Site, build command blank, publish directory "."
